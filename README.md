# FridgeSense

FridgeSense is an AI-powered kitchen assistant that helps households turn fridge photos into practical meal and shopping decisions. The app uses AI vision to identify ingredients, organize grocery needs, and suggest what to cook tonight.

Live site: [fridgesense.vercel.app](https://fridgesense.vercel.app)  
Repository: [github.com/wayne-pp/Fridgesense](https://github.com/wayne-pp/Fridgesense)

## Features

- Upload or capture fridge photos for AI ingredient recognition
- Generate shopping lists from detected ingredients and missing pantry items
- Group shopping lists by Costco, Walmart, Target, and Asian grocery stores
- Recommend dinner ideas based on what is already in the fridge
- Provide a clean, mobile-friendly kitchen assistant experience

## Tech Stack

- Next.js 16
- TypeScript
- Tailwind CSS
- Claude AI Vision
- Vercel

## Local Development

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
